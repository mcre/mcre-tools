# 初期マップ

Git管理対象のマップ定義。1マップにつき1つのJSONを置き、`../maps.ts`のレジストリから読み込む。
ブラウザで読み込める静的データで、ファイルシステムや最適化スクリプトには依存しない。
現時点の画面は`open`を使用する。ユーザー向けの選択UIはまだ追加していない。

| ID          | 内容                                  |
| ----------- | ------------------------------------- |
| `open`      | 壁なし。従来と同じ2か所の餌           |
| `detour`    | 巣と餌の間の壁を、上か下から迂回する  |
| `gap`       | 上下まで続く壁の21セル幅の通路を通る  |
| `zigzag`    | 開口が上下交互にある2枚の壁を迂回する |
| `scattered` | 大きさをそろえた6か所の餌             |
| `far`       | 巣から約100・115セル離れた餌          |
| `fork`      | 直進先の少量の餌と、上下の分岐先の餌  |
| `loop`      | 壁の手前の少量の餌と、壁の反対側の餌  |
| `rooms`     | 最初の部屋の少量の餌と、別室の餌      |
| `shortcut`  | 細い近道と、幅の広い迂回路            |

`id`は固定ID、`name.ja/en`は将来の選択UIにも使える表示名。
`columns/rows`は論理セル数、`nest`は連続座標の中心と半径。
`food`は整数セルの中心座標`x/y`、半径`radius`、1セルの個数`amount`を持つ円形の餌。
例えば`x: 110, y: 55`の中心は描画上では`(110.5, 55.5)`。
`walls`は左上の整数セル`x/y`と`width/height`を持つ長方形。

アリの匹数、乱数のseed、モデルのパラメータはマップ定義に入れない。
`createMapLayout(id, seed)`が共通パラメータを使った独立した配置データを生成する。
`ANT_MAPS`からID・名前を取得でき、選択UIを追加しても同じ定義を再利用できる。

追加するときはJSONとレジストリへ追加し、`antsMaps.spec.ts`の範囲・重複・巣の保護・餌への到達性の確認も追加する。
到達性の探索はマップのテストだけで実行し、アリの移動には使用しない。

`tools/ants/exploration-protocol.json`は、各餌への移行と近道の再発見を評価する別の実験条件。
近道の評価では`shortcut`の細い通路を一時的に壁で閉じ、迂回路ができてから消しゴムと同じ処理で開く。
変更時刻や計測窓はマップ定義に含めず、アリの移動にも渡さない。
