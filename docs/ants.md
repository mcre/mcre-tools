# アリ観察

`/ja/ants` と `/en/ants` の、餌と壁へ介入できる観察箱。
採餌モデルは自前のTypeScript、描画はブラウザ標準のCanvas 2D、操作UIはVue/Vuetifyを使う。
経営・育成・パズル要素、外部APIは使用しない。

2026-10-07のUI見直しで、自動保存、ファイル保存・読み込みを取り除いた。
ページを開くと「開けた場所」の初期状態から始める。初期マップの選択はページを開いている間だけ保持する。過去のIndexedDBデータにはアクセスしない。

観察エリアの上に再生操作とフェロモンの凡例、下に数値と編集操作を置く。
フェロモンは常時表示。サイズは3～31の奇数、再生速度は0.5～32倍（0.25刻み）のスライダーで選ぶ。
仕組みと詳しい凡例は折りたたみ、スマホでは編集操作を画面下に固定する。
拡大表示は同じCanvasを画面いっぱいの領域へ広げる。実行状態と編集を保持し、閉じるボタンかEscapeで戻る。

## 主な構成

- `src/pages/ants.vue`: 操作UI、ブラシ範囲の表示、リセット、SEO。
- `src/composables/useAntSimulation.ts`: mount後のブラウザリソース、固定tickと描画、Pointer Events。
- `src/composables/useAntExpandedView.ts`: 拡大表示、ページのスクロール抑制、キーボード操作とフォーカス復帰。
- `src/lib/ants/types.ts`: 配置、実行状態、モデルとUIの型。
- `src/lib/ants/config.ts`: 全マップ共通の既定パラメータ。
- `src/lib/ants/maps/*.json`, `maps.ts`: Git管理対象の初期マップ定義と読み込み用レジストリ。日英の表示名を持ち、画面の選択UIとオフライン評価で共用する。
- `src/lib/ants/model.ts`, `random.ts`, `edit.ts`, `clock.ts`: DOM/Vueから独立したモデル。
- `src/lib/ants/renderer.ts`: 状態を読むCanvas 2D描画。
- router、日英locale、`public/llms.txt`、`public/img/ants/`: 一覧、ナビゲーション、メタ情報、アイコン。
- `src/tests/vitest/unit/ants*.spec.ts`, `src/tests/playwright/ants/test.spec.ts`: モデル、編集、ライフサイクル、preview上の操作検証。

ページは遅延importされ、ブラウザリソースとモデルはmount後だけ生成する。
AutoImportの型は既存のVite/Vitest pluginが再生成する。

## モデル

以下は2026-10-08の経路再探索の調整後の条件。距離は描画ピクセルではなく論理セル単位。

### 世界と初期状態

| 条件                 | 値                                                                                           |
| -------------------- | -------------------------------------------------------------------------------------------- |
| 世界                 | 240×160セル。壁と餌はセル単位、アリの位置と方向は連続値                                      |
| アリ                 | 300匹。個体同士の衝突や混雑による減速はない                                                  |
| 巣                   | 中心(75, 80)、半径5セル。巣内は円の内側と境界                                                |
| 初期配置             | 巣の中心から半径3セル以内に面積一様で配置。各個体は外向き、運搬量0                           |
| 初期方向             | 0～2πの一様乱数。初期速度係数は0.72～1.28、旋回のゆらぎは0                                   |
| 初期の餌             | セル中心(110.5, 55.5)、(125.5, 105.5)の2か所。各半径3セルの円形29セル、1セル90個。合計5220個 |
| 初期の壁・フェロモン | いずれも0                                                                                    |
| 乱数                 | seed 20261004のMulberry32。同じ配置・操作・tick数なら同じ結果                                |

配置と実行状態を分け、ユーザーの編集は両方へ適用する。採餌は配置の餌量を減らさない。
「リセット」は選択中の初期マップに戻し、編集した配置も破棄して、餌・壁・アリ・フェロモン・搬入数・経過時間を初期状態へ戻して停止する。
速度、編集ツール、ブラシサイズの選択は保つ。確認ダイアログはなく、1回の操作で初期化する。
初期の餌は巣の中心から約43・57セル離れており、巣から直接においを感知できない。
リセット横のメニューから10種類の初期マップを選べる。選択直後にその配置で初期化し、停止する。初期選択は`open`で、以後のリセットも選択中のマップに戻す。

### 時間

1/30秒の固定tick。再生速度はtick数だけを変える。
1フレームの上限は`min(32, max(8, ceil(再生速度)))`tickとし、停止・非表示からの復帰では経過時間を捨てる。
フレーム間隔は最大250msとして扱い、上限まで処理したときは残った待ち時間を捨てる。32倍でも30fps以上なら毎秒960tickを処理できる。
速度の変更でも時計をリセットする。処理が追いつかない場合はモデル時間の進みが遅くなる。

### 移動と餌の取得・搬入

| 条件                 | 値・ルール                                                                                            |
| -------------------- | ----------------------------------------------------------------------------------------------------- |
| 基準速度             | 9セル/モデル秒。1tickの移動は`9 / 30 × 速度係数`                                                      |
| 速度係数             | 毎tick一様乱数で最大±0.0125変化し、0.65～1.35に制限。実際の速度は5.85～12.15セル/秒                   |
| フェロモンのセンサ   | 前方から左右各0.7rad（約40.1度）と正面の3点。距離は個体ごとに3.5～6.5セル。点が属するセルの濃度を読む |
| フェロモンによる旋回 | 最大濃度が0.0001より大きければ、左右の濃度差に応じて滑らかに曲がる。前方濃度が高いほど直進を保つ      |
| 旋回量               | フェロモンによる旋回は最大4.5rad/秒、1tick約8.59度                                                    |
| ゆらぎ               | 毎tick `w = 0.9 × 前のw + 0.1 × 一様乱数[-1,1]`                                                       |
| ランダム旋回         | `0.09 × (別の一様乱数[-1,1] + 2 × w)`radに倍率をかけ、フェロモン・餌による旋回に加える                |
| ランダム旋回の倍率   | センサの最大濃度が0.001より大きい、または餌のにおいを感知した場合1.5。それ以外は2.4                   |
| 障害物               | 移動線分に壁・外周があればそのtickは移動せず、90～270度の一様乱数で向きを変える。斜めの角抜けも不可   |
| 餌の取得             | 運搬しておらず、巣の外にいて、現在セルに餌があれば1個取得。餌は1個減り、180度反転する                 |
| 搬入                 | 1個運搬した状態で巣の円内へ入ると、搬入数を1増やし、運搬量を0にして180度反転する                      |

取得・搬入は各tickの移動前に判定する。各個体の処理は順番に行い、最後の餌1個を複数匹が取得することはない。
各個体は生成時に0.7～1.3の一様乱数の係数`q`を持つ。センサ距離は`5 × q`、濃度の重みの指数は`k = 0.9 / q`。
左・前・右の濃度から`L^k`、`2 × F^k`、`R^k`を計算し、旋回量を`(R^k - L^k) / (L^k + 2 × F^k + R^k) × (4.5 / 30)`radとする。
左右の重みが等しければフェロモンによる旋回は0。どちらかへ傾いているほど大きく曲がる。
手がかりがない場合はランダム旋回だけで探索する。濃度がある場合も通常のランダム旋回を残す。
`q`は探索中・運搬中とも同じで、途中では変化しない。速度の係数とは独立した乱数で決める。
固定割合の「探索役」は設けない。時間を決めてフェロモンを無視する実験用モードは、既定値では無効。
運搬中も巣の方向へ直接曲がらず、近くの巣へのフェロモンとランダム旋回で移動して巣に入ったとき搬入する。
全体地図の経路探索、餌位置の共有、移動経路の記憶、個体間の直接通信はない。
空腹、疲労、寿命、繁殖、巣の成長はモデルに含めない。

### 餌のにおい

探索中だけ、現在位置から半径8セル未満の地面の餌を感知する。
餌セルごとの方向を、`min(残量, 100) × (1 - 距離 / 8)²`で重み付けして合成する。
残量が多く近い餌ほど強く、1セルの残量100個で強さの増加は止まる。
合成した方向へ最大1.2rad/秒（1tick約2.29度）の旋回を、フェロモンによる旋回に加える。
互いに相殺して合成方向がほぼ0（ベクトル成分の絶対値合計1e-9以下）の場合は曲がらない。
壁・外周・斜めの角で遮られた餌は感知しない。風や壁を回り込む拡散はモデル化しない。
運搬中は反応しない。食べ尽くすか消しゴムで消した餌には、その時点から反応しない。
現在の近くの餌だけから算出し、においの地図・蓄積・残留は持たない。フェロモンの色にも表示しない。

### フェロモン

フェロモンは表示・内部ともに2種類。各個体は運搬の有無だけで、たどる種類と残す種類を切り替える。

| 状態   | たどる種類                   | 残す種類                     | 付着量の基準地点       |
| ------ | ---------------------------- | ---------------------------- | ---------------------- |
| 探索中 | 餌へのフェロモン（青）       | 巣へのフェロモン（オレンジ） | 最後に入った巣         |
| 運搬中 | 巣へのフェロモン（オレンジ） | 餌へのフェロモン（青）       | 最後に餌を取得した場所 |

移動後のセルへ1tickあたり`2.5 × exp(-d / 35)`を残す。`d`は基準地点からの累積移動距離。
巣の円内にいるtickと餌の取得時に距離を0へ戻し、移動するほど付着量を減らす。
これは基準地点との直線距離ではなく、実際に移動した距離の合計。巣の方向・移動経路・餌の発見経験は記憶しない。
衝突で移動しなかったときは距離が増えないが、付着は行う。一時停止・再開では距離を保つ。
巣そのものからの放出や、あらかじめ用意した巣への濃度勾配はない。初期状態では両方の濃度が0で、アリだけが付着する。
両方とも独立して上下左右の開いた隣接セルへ濃度差に応じて拡散する。拡散係数0.6、1tickの係数は0.02。
蒸発率0.12/秒で、毎tick `exp(-0.12 / 30)`倍。付着なしなら半減期は約5.8秒。
それぞれの濃度を0～100に制限する。壁のセルは両方の濃度0、壁・外周を越える流出はない。
全個体がtick開始時の値を読んだ後、そのtickの付着をまとめて反映する。
描画はモデルやPRNGを変更しない。

2種類を使い分ける仕組みは、局所的なフェロモンだけで往復させる人工採餌モデルの考え方を採用している。
Panait & Lukeのモデルは周辺濃度から付着量を調整するが、この実装では基準地点からの累積移動距離による減衰に簡略化した。
2種類という区別や付着量は観察用モデルの仮定であり、特定の実在種の実測値を再現するものではない。
餌の栄養・品質、混雑、既存フェロモンによる付着抑制は扱わない。

- [Panait & Luke (2004), Ant Foraging Revisited](https://faculty.cc.gatech.edu/~turk/bio_sim/articles/ant_foraging_revisited.pdf)
- [Sebastian Lague, Ant Simulation](https://github.com/SebLague/Ant-Simulation)

## 編集と表示

餌・壁・消しゴムは円形ブラシ。直径は3～31セルの奇数をスライダーで選び、既定は11セル。
選択した範囲をポインターの周囲に表示する。
Pointer Eventsの間を補間し、同じストロークでは各セルを一度だけ編集する。
論理座標で処理するためDPRによって編集範囲は変わらない。
巣の円内にセル中心がある場所では、すべての編集を無視する。
餌ブラシは1セル100個を加え、1セル最大65535個。壁があるセルには置けない。
壁は現在の餌、または再開用の配置に餌があるセルには置けない。食べ尽くした餌の場所も、消しゴムで配置を消すまでは置けない。
壁を置いたセルのフェロモンは0にし、埋まったアリだけを近くの空きセルへ押し出す。この処理は壁の編集時だけ行う。
消しゴムは壁と地面の餌だけを消し、フェロモン・アリ・運搬中の餌・搬入済みの数は変えない。

操作ボタンは実行中に「一時停止」、停止中に「再開」。
青色は餌へのフェロモン、オレンジ色は巣へのフェロモン。重なる場所は2種類の濃度比で色を混ぜる。時間とともに薄れる。
表示の強さは`min(0.8, (餌への濃度 + 巣への濃度) / 18)`。合計濃度14.4以上では強さが変わらなくなるが、色の混合比と内部の濃度は変化する。
探索中と運搬中のアリは近い暗色にそろえ、運搬中は頭の先に小さな緑色の餌を描く。
フェロモンは常時表示し、濃度を描画の透明度へ反映する。
通常は自動再生し、`prefers-reduced-motion: reduce`なら停止状態で始める。
初期化操作では停止する。保存機能はなく、ページへの再訪もデモの初期状態で始める。

## 採餌・性能の確認

最初の6マップでの調整は[従来のパラメータ調整の記録](ants-optimization.md)に残す。
その後、古い道への固定を調べる4マップを追加し、濃度差に応じた滑らかな追従と個体ごとのセンサの差へ変更した。
後から開いた近道の利用率、帰りに実際に歩いた距離、各餌からの回収、既存6マップの採餌量で比較する。
条件と最新結果は[経路再探索の記録](ants-exploration.md)、採用値と集計結果は[評価結果JSON](ants-exploration-results.json)を参照。

固定seedの32×24セル・80匹の小世界では、障害物なしと隙間のある壁で60秒相当以内に10個以上を搬入する。
完全に閉じた壁の向こうには到達せず、餌の総量は保存される。

2026-10-08、macOS上のローカルChromium 153で標準デモを測定した。

| 時間 | 運搬中 | 搬入済み | 地面の餌 |
| ---- | -----: | -------: | -------: |
| 10秒 |     36 |        2 |     5182 |
| 30秒 |    153 |      157 |     4910 |
| 60秒 |    200 |      473 |     4547 |

純モデル1800tick、2種類まとめての拡散300回、Canvas描画300回（幅1000px、DPR 1）。
1tickの平均は0.64ms、2種類の拡散は合計0.29ms、描画は0.12ms。
実画面では1倍・8倍・32倍速をそれぞれ12秒計測し、すべて約60fps、50msを超える長時間処理は0回だった。32倍では実時間約12秒に対してモデル時間384.5秒が進み、実測速度は約32.0倍だった。
直前の搬入量を重視した既定値の60秒の搬入数861個から473個に減った。経路再探索の評価と、短時間の搬入量は別に記録する。
数値は端末とブラウザに依存する。
